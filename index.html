Featured Project

Masarak turns recruitment into a focused full-stack mobile workflow.

A full-stack recruitment platform and graduation project, connecting employers with job seekers using Flutter for the frontend and ASP.NET Core for the backend.

Masarak solves fragmented hiring by pairing a polished Flutter candidate experience with employer-side job posting, CV submission, and candidate qualification workflows.

Flutter handles the experience layer, ASP.NET Core powers the backend, and RESTful APIs move job, profile, CV, and candidate data through clean boundaries.

The project demonstrates production thinking: maintainable modules, backend integration, scalable data models, and user journeys designed for clarity and reliability.
